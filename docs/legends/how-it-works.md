# How GitHub Legends works

GitHub Legends turns verified GitHub activity into a game-style profile: levels, seasonal ranks, heroes, medals, quests and a world map. Everything is computed by an open, deterministic engine in [`legends/`](../../legends/), and every number can be traced back to a ledger entry.

## What counts

- **Only verified, qualifying activity.**
  - Commits must be authored by the player in a repository they own or contribute to.
  - Merged pull requests, reviews of other people's pull requests, issues and releases are read from the GitHub API.
  - Bot accounts, merge commits, empty commits, forks, declared automation and duplicated commits earn nothing.
- **Diminishing returns.**
  - Commit EXP shrinks after 5 commits a day and stops after 10.
  - Pull requests, reviews, issues and releases have daily caps.
  - Volume alone cannot climb the ranks: higher ranks need *contested objectives*, meaning work that involved another person, such as a pull request merged after someone else's approval.
- **Private work** is counted only as an anonymous number of contributions, and only if the owner turns it on. No private repository name is ever shown.

## The systems

| System | In short |
| --- | --- |
| **EXP and level** | Lifetime EXP from qualifying activity. Levels 1–100 never go down |
| **Battles** | Each day with activity is a battle: score ≥ 30 is a Victory (1 star), score ≥ 100 with a contested objective is an MVP (+1 star). At most 5 stars per week |
| **Rank and seasons** | Seasons are calendar quarters (Asia/Jakarta time). Stars raise your rank from Initiate to Eternal. Some tiers need a promotion trial. A new season starts lower (soft reset); lifetime progress is never reset |
| **Heroes and mastery** | Each technology is an original hero. Mastery points follow verified commit EXP split by language bytes. **Mastery reflects activity volume, not assessed skill** |
| **Emblems and equipment** | Emblems level up from verified domain activity (frontend, backend, AI/ML, …). Equipment comes from tools detected in project files. Self-declared tools are marked ✎ and never rewarded |
| **Quests** | Daily, weekly and season quests drawn from a fixed, seeded board. Quests pay Battle Points only |
| **Medals** | Game achievements with rarity. They are separate from the real-world achievements listed in the profile |
| **World map** | Regions unlock with level and emblem progress; checkpoints are cleared by medals and milestones |

## Provenance marks

- ✔ **Verified**: counted directly from GitHub data.
- Σ **Derived**: computed by the rules from verified data (levels, ranks, mastery).
- ✎ **Self-declared**: chosen or typed by the player (main hero, declared tools). Never rewarded.

## Freshness

The block is regenerated by a scheduled run. A day closes 48 hours after it ends, so late data can still arrive. If the last complete data refresh is more than 3 days old, the profile says so instead of showing outdated numbers as current.

## Originality

GitHub Legends is inspired by MOBA lobbies. All names, heroes, crests, maps and art are original to this project, and no official game assets are used.
